# Upload this project to your GitHub account

The ZIP supplied by InnoCircuitsLab's project assistant is **a local upload package, not an existing hosted GitHub repository**.

1. Sign in to your GitHub account and choose **New repository**.
2. Suggested repository name: `ESP32-S3-LD2450-Multi-Target-Radar`.
3. Choose **Public**, and leave the “Add a README” / license / `.gitignore` setup boxes **unchecked**, because these files are already provided in the package.
4. Create the repository.
5. Open the empty repository's **uploading an existing file** link or **Add file → Upload files**.
6. Extract the provided ZIP. Drag the **contents inside** the `ESP32-S3-LD2450-Multi-Target-Radar` folder into the upload area. Preserve `firmware/`, `docs/`, `extras/`, and `assets/` paths.
7. Commit the files to `main` (for example, commit message `Initial release: ESP32-S3 LD2450 radar UI V3`).
8. Open the repository front page. Ensure `README.md` displays the wiring diagram and that the `.ino` file opens properly.
9. **Only after the upload succeeds**, film the GitHub repository page and copy its actual URL into the video description.

Do not drag the outer folder itself if you want `README.md` displayed at the root of your repo.
